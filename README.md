# C Server

This is a single header file web server implementation in C (open source and unilicense). It's still a work in progress so beware before using it.

We're implementing the following features:
- http server
- tcp server
- udp server

We're desiging it to be minimal and efficient to be useful in small embedded systems (especially udp and tcp servers) as
well as general web servers looking for speed or control with C.

Once our API stabilizes and we've done some good real world testing, we'll put some example usage here. 


If you'd like to contribute, feel free to make a pull request or report an issue.
